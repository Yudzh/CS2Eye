# Итерация 09 — сила карт и сравнение map pool

## Пользовательский сценарий

В карточке команды пользователь видит силу каждой карты, надёжность оценки и объяснение факторов. На странице сравнения отдельный блок сопоставляет map pool двух текущих составов или двух организаций. Результат описывает статистику и не является прогнозом матча или veto.

## Источники данных

Расчёт выполняет `team_map_strength_service.py` только по сохранённым строкам `team_map_aggregates`. Используются уровни `organization` и `roster` без смешивания, scope `all`, окна `recent:5/10/20`, группы `rank:top_15` и `rank:top_16_30`, CT/T, `sample_size_score` и `freshness_score`. `.dem` повторно не читаются, внешние источники и отдельная таблица результатов не используются.

## Формула performance

Для каждого scope: `scope_performance = map_win_rate × 0.60 + round_win_rate × 0.40`. Если доступен только один winrate, он используется без штрафа.

Компоненты:

- общий результат `all` — 45%;
- первое окно среди recent 5, 10 и 20 с минимум тремя картами — 25%;
- средневзвешенный результат против Top-15 и Top 16–30 — 20%; вес группы равен соответственно `min(maps, 5) × 1.5` и `min(maps, 5) × 1.0`;
- сила сторон — 10%; слабая сторона имеет вес 65%, сильная 35%.

Недоступные компоненты исключаются, оставшиеся веса нормализуются до 100%. Промежуточные вычисления не округляются.

## Confidence и итоговая сила

`confidence = sample_size_score × 0.50 + freshness_score × 0.25 + min(100, ranked_maps × 10) × 0.15 + min(100, min(CT rounds, T rounds) / 24 × 100) × 0.10`.

Уровни: ниже 40 — низкая, от 40 до 70 — средняя, от 70 — высокая надёжность. При числе карт меньше трёх status равен `not_enough_data`, а числовой strength отсутствует.

Для доступной выборки: `reliability_factor = 0.5 + 0.5 × confidence / 100`; `map_strength_score = 50 + (performance_score - 50) × reliability_factor`. Итоги ограничиваются диапазоном 0–100, API округляет финальные значения до двух знаков.

Сервис возвращает объяснения общего результата, recent form, сильных соперников, сторон и confidence adjustment. Предупреждения покрывают малую выборку, устаревание, отсутствие Top-30 матчей и недостаток CT/T данных.

## API

- `GET /api/v1/analysis/teams/{team_id}/maps` — аддитивное поле `strength` каждой карты;
- `GET /api/v1/analysis/teams/{team_id}/maps/{map_name}` — тот же расчёт в деталях карты;
- `GET /api/v1/analysis/compare/teams/{team_a_id}/{team_b_id}/maps?aggregation_level=current_roster|organization` — объединение карт, сравнимость, преимущество и summary.

Все ответы описаны Pydantic-схемами. Для `current_roster` выбираются только агрегаты с текущим `roster_id`; отсутствие roster или его карт является штатным пустым состоянием.

## UI

Карточка команды показывает strength, confidence badge, W–L, winrate карты и сторон, свежесть, Top-30 scopes, breakdown, warnings и прежние последние матчи. Доступна сортировка по силе.

Страница сравнения содержит map-pool таблицу между общим сравнением и H2H. Переключатель меняет текущие составы и историю организаций. Несравнимые карты объясняют отсутствие данных, roster или минимальной выборки.

## Ограничения

Итерация не рассчитывает вероятность победы, betting signal, коэффициенты, veto/pick/ban, BO3/BO5, economy, utility или pistol analytics. Нет LLM, scheduler, фоновых обновлений и новых внешних источников.

# Итерация 04 — исторический рейтинг соперника

## Назначение

Группа соперника для внутреннего рейтинга определяется на дату матча, а не
по текущему месту команды. Дата берётся только из `demo_files.match_date`.
Формула внутреннего рейтинга и игровые показатели не изменяются.

## История рейтинга

Используется существующая таблица `team_ranking_snapshots`. Каждый успешный
импорт BO3.gg Top 40 создаёт или обновляет запись с ключом
`(team_id, ranking_date, source)`. Повторный импорт той же даты идемпотентен.
Дата берётся из ответа BO3.gg; ответ без согласованной даты отклоняется
существующей валидацией импорта.

## Разрешение места соперника

Для связанной команды выбирается последний snapshot, удовлетворяющий условиям:

```sql
WHERE team_id = :opponent_team_id
  AND ranking_date <= :match_date
ORDER BY ranking_date DESC
LIMIT 1
```

Snapshot после матча никогда не используется. Максимальная допустимая давность
задаётся настройкой `MAX_RANKING_SNAPSHOT_AGE_DAYS` (по умолчанию 14 календарных
дней). Результат сохраняет один из источников:

- `historical_snapshot` — найден подходящий snapshot;
- `current_fallback` — истории нет, она устарела или отсутствует дата матча,
  поэтому использован `teams.current_rank`;
- `unknown` — не связана команда или отсутствует и историческое, и текущее место.

Группы остаются прежними: 1–15 — `top_15`, 16–30 — `top_16_30`, 31+ —
`outside_top_30`, без места — `unknown`.

## Переклассификация

Переклассификация не читает `.dem` и не изменяет kills, deaths, assists, ADR,
KAST или рассчитанный рейтинг конкретной карты. Она обновляет только поля
соперника и затем пересчитывает агрегированные рейтинги затронутых игроков.

Одна демка:

```http
POST /api/v1/demos/123/reclassify-opponent-ranks
```

Турнир и год:

```http
POST /api/v1/demos/reclassify-opponent-ranks
Content-Type: application/json

{
  "tournament_name": "IEM Cologne",
  "year": 2026,
  "only_unknown_or_fallback": true
}
```

При массовой операции ошибка одной демки откатывает только её изменения и не
останавливает остальные. Обычный импорт нового рейтинга намеренно не меняет
ранее сохранённые demo stats: это происходит только при повторном парсинге с
`replace_existing=true` либо через явный reclassify endpoint.

## Известные ограничения

Связывание команд остаётся точным по нормализованным именам и существующим
алиасам; fuzzy matching и ручной редактор historical rank не добавлялись.
Качество исторической классификации ограничено фактически накопленными датами
импортов BO3.gg.

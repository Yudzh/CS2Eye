# Итерация 3 — внутренний рейтинг по уровню соперника

## Три рейтинга

Для игрока сохраняются три независимые выборки CS2Eye Internal Rating v1:

- общий рейтинг — все успешно распарсенные демки;
- против Top 1–15 — только строки с `opponent_rank_group = top_15`;
- против Top 16–30 — только строки с `opponent_rank_group = top_16_30`.

Каждая выборка является средним рейтингов карт, взвешенным по числу раундов, и имеет собственные `maps_count` и `rounds_count`. `outside_top_30` и `unknown` входят только в общий рейтинг.

## Определение соперника

На конце валидных раундов парсер получает `team_clan_name`. Названия двух команд карты нормализуются и точно сопоставляются с `teams.name` без fuzzy matching и без фильтра по активности. Текущая команда игрока не используется: команда игрока и соперник берутся только из конкретной демки.

Диапазоны snapshot:

```text
1–15  → top_15
16–30 → top_16_30
31+   → outside_top_30
null  → unknown
```

В `demo_player_stats` сохраняются команда игрока, соперник, его `current_rank` и группа. Это исторический snapshot: последующие обновления `teams.current_rank` его не меняют. Обновить классификацию можно только повторным парсингом с `replace_existing=true`.

Если в демке не ровно две команды, название не найдено или совпадение неоднозначно, статистика сохраняется с группой `unknown`. Parse run остаётся успешным, а API возвращает диагностическое сообщение.

## API

Повторная классификация конкретной демки:

```bash
curl -X POST \
  'http://localhost:8000/api/v1/demos/10/parse?replace_existing=true'
```

Проверка snapshot каждого игрока:

```bash
curl http://localhost:8000/api/v1/demos/10/player-stats
```

Фрагмент ответа:

```json
{
  "demo_team_name": "NAVI",
  "opponent_team_name": "Spirit",
  "opponent_rank": 8,
  "opponent_rank_group": "top_15"
}
```

Карточка игрока и DTO активного состава возвращают общий рейтинг, `internal_rating_top15`, `internal_rating_top16_30` и отдельные размеры выборок. Эти показатели не влияют на BO3 Avg, `player_strength`, team strength или сравнение команд.

# Итерация 05: результат карты из demo

`demo_files` остаётся технической сущностью файла. Игровой результат хранится в
`demo_map_results`; связь один-к-одному обеспечена `UNIQUE(demo_file_id)`, а удаление
файла каскадно удаляет результат.

## Источник и нормализация

Основной источник — header, финальный tick и завершённые `round_end` события `.dem`.
Имя файла не участвует в определении результата. `de_*` имена стандартных карт
приводятся к короткому коду единственной функцией `normalize_map_name`. Безопасное
неизвестное имя сохраняется со статусом `needs_review`.

Поддерживаемые карты: Mirage, Inferno, Nuke, Ancient, Anubis, Dust2, Train,
Overpass, Vertigo и Cache (`de_cache → cache`).

Команды разрешаются общим `demo_team_resolver`: Unicode/case/punctuation
нормализация, точное совпадение и существующие детерминированные aliases. Fuzzy
matching отсутствует. Исходное имя всегда сохраняется; неоднозначная или неизвестная
команда получает `team_id = null`. Та же логика используется player stats.

## Результат и качество

Победитель вычисляется только сравнением счёта, `rounds_count` — суммой очков.
Явные overtime-периоды парсера имеют приоритет; fallback для MR12 требует минимум
12 раундов у обеих команд и победный счёт выше 13. Расхождение числа событий и суммы
счёта сохраняет счёт, добавляет warning и `needs_review`.

Статусы: `complete`, `partial`, `needs_review`, `invalid`. Некорректные метаданные
не откатывают успешно рассчитанную статистику игроков. Техническая ошибка записи —
ошибка parse run.

## Повторный анализ и замена

Повторный parse обновляет существующую строку, поэтому операция идемпотентна.
Замена содержимого файла удаляет старый map result и player stats и возвращает parse
run в `pending`. Миграция не пытается угадать результаты старых файлов.

## API

- `GET /api/v1/demos/{id}/map-result` — полный результат; до извлечения отвечает 404.
- `PATCH /api/v1/demos/{id}/map-result` — карта, команды и счёт. Backend заново
  вычисляет победителя, раунды, overtime и качество.
- `GET /api/v1/demos` — краткий результат без N+1 (один запрос результатов на список).
- `GET /api/v1/meta/maps` — общий справочник для формы.

Ручная смена команд не переносит игроков между сторонами. Расхождение с
`demo_player_stats` возвращается как `player_team_result_mismatch`.

## Ограничения

Раунды, экономика, бомбы, CT/T метрики, BO3, veto и турнирная сетка не моделируются.

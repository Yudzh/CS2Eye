# Итерация 05 — сравнение двух команд

## Пользовательский сценарий

Страница `/compare` загружает активные команды текущего Top-30 из БД. Два
селектора позволяют выбрать разные команды, после чего интерфейс запрашивает
готовое сравнение. Выбор сохраняется как `team_a` и `team_b` в URL и
восстанавливается после перезагрузки.

Сравнение не обновляет данные и не обращается к BO3.gg. Оно использует команды,
игроков, memberships, роли и рассчитанную силу, уже доступные в итерации 04.

## API

```http
GET /api/v1/teams/compare?team_a_id=12&team_b_id=27
```

Допускаются только разные активные команды. Одинаковые ID дают `400`,
отсутствующая или неактивная команда — `404`. Ответ содержит обе стороны,
активные игровые составы, тренеров как справочную информацию, готовую
расшифровку силы, рейтинг, сравнение ролей и детерминированные пояснения.
Результат не сохраняется в отдельной таблице.

## Преимущество и относительная сила

Преимущество по силе определяется только при абсолютной разнице не меньше
5 пунктов. Граница `5.0` включена. При меньшей разнице явного преимущества нет.

Относительное отображение нормализует два неотрицательных значения:

```text
safe_a = max(score_a, 0)
safe_b = max(score_b, 0)
A = round(safe_a / (safe_a + safe_b) * 100, 2)
B = round(100 - A, 2)
```

Если сумма равна нулю, оба процента отсутствуют. Эти значения описывают только
относительную силу выбранной пары и не являются вероятностью победы.

## Сравнение ролей

Роли возвращаются в порядке `igl`, `awper`, `entry_frag`, `lurk`,
`anchor_support`, `rifler`. Для нескольких игроков одной роли используется
средняя эффективная сила. Отсутствующая сила игрока заменяется на 50 с явной
отметкой fallback.

Если роль отсутствует хотя бы с одной стороны, её значение остаётся `null`:
оно не превращается в ноль и преимущество не назначается. Если обе стороны
заполнены, действует тот же порог в 5 пунктов.

## Осознанно исключено

В итерацию не входят карты и map pool, матчи, head-to-head, текущая форма,
veto, турниры, коэффициенты, прогнозы и вероятность победы, ставки,
LLM-анализ, внешние запросы и автоматическое обновление. Формула силы команды
не дублируется: comparison-сервис вызывает сервис итерации 04.

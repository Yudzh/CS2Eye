# Итерация 1 — загрузка demo-файлов

Реализован минимальный контур хранения исходных `.dem`: множественная потоковая загрузка, рекурсивный поиск демок во вложенных ZIP/RAR-архивах, SHA-256, ограничение размера, атомарная замена, метаданные в PostgreSQL и просмотр списка по турниру и году. Demo-файлы не парсятся.

## Хранилище

Корень задаётся через `DEMO_STORAGE_ROOT` (по умолчанию `/app/storage`). Относительный путь в БД и путь на диске имеют вид:

```text
demos/tournaments/<tournament_slug>/<year>/<YYYY-MM-DD>/<filename>
```

Например: `demos/tournaments/iem-cologne/2026/2026-07-28/map-1.dem`. Исходное имя турнира хранится отдельно, имя файла остаётся читаемым. Максимальный размер одного файла задаёт `DEMO_MAX_FILE_SIZE_BYTES` (по умолчанию 2 GiB).

## API

Загрузка одной или нескольких демок:

```bash
curl -X POST http://localhost:8000/api/v1/demos/upload \
  -F "tournament_name=IEM Cologne" \
  -F "match_date=2026-07-28" \
  -F "files=@navi-vs-spirit-m1-mirage.dem" \
  -F "files=@navi-vs-spirit-m2-dust2.dem"
```

Вместо отдельных демок можно передать один или несколько `.zip` или `.rar`. Вложенные ZIP и RAR в любом сочетании обрабатываются рекурсивно до глубины `DEMO_ARCHIVE_MAX_DEPTH` (по умолчанию 5). Каталоги из архива не переносятся в хранилище: для каждой найденной демки безопасно берётся только имя файла. Прочие файлы игнорируются. Архив без единой `.dem` возвращает `failed`.

Каждый файл получает независимый статус:

- `created` — новая запись и новый файл;
- `replaced` — то же имя, но новое содержимое; файл атомарно заменён;
- `unchanged` — SHA-256 совпал, файл не перезаписывался;
- `failed` — валидация или запись завершилась ошибкой; другие файлы запроса продолжают обрабатываться.

Список демок:

```bash
curl "http://localhost:8000/api/v1/demos?tournament_name=IEM%20Cologne&year=2026"
```

Результат сгруппирован по датам от новых к старым, файлы внутри даты отсортированы по имени. Поиск турнира выполняется по нормализованному slug.

## Проверка контейнера

```bash
docker compose -f compose.local.yml exec api \
  find /app/storage/demos -type f
```

```bash
docker compose -f compose.local.yml exec api \
  ls -lah /app/storage/demos/tournaments/iem-cologne/2026/2026-07-28
```

## Не входит в итерацию

Нет поддержки 7z, парсинга demo, извлечения команд/карт, аналитики, очередей, удаления, скачивания и редактирования метаданных. Отдельная сущность турнира не создаётся.
